# Password Checker

Ένα απλό εργαλείο γραμμής εντολών (CLI) σε Python που ελέγχει αν ένας κωδικός πρόσβασης είναι αρκετά ισχυρός, με βάση το μήκος και τον αριθμό ειδικών χαρακτήρων.

## Απαιτήσεις

- Python 3.6 ή νεότερη (δεν χρειάζεται καμία εξωτερική βιβλιοθήκη)

## Πώς να το τρέξεις

```bash
python3 Main.py
```

Το πρόγραμμα θα σου ζητήσει να πληκτρολογήσεις έναν κωδικό. Θα σου δείξει αν είναι αδύναμος ή ισχυρός, και γιατί.

Για έξοδο ανά πάσα στιγμή: `Ctrl+C`.

## Κριτήρια ελέγχου

Ένας κωδικός θεωρείται **ισχυρός** όταν:

1. **Μήκος** ≥ 12 χαρακτήρες
2. **Ειδικοί χαρακτήρες**: περισσότεροι από 2 από τους `@ # ! $ % ^ *`

Αν το μήκος είναι μικρό, το πρόγραμμα σου το λέει αμέσως και σε ξαναρωτάει.
Αν το μήκος είναι εντάξει αλλά λείπουν ειδικοί χαρακτήρες, σου δείχνει πόσους έχεις βρεθεί και σε ξαναρωτάει.
Όταν ο κωδικός περάσει και τα δύο κριτήρια, το πρόγραμμα τυπώνει επιβεβαίωση και τερματίζει.

## Δομή αρχείου

- `banner()` — τυπώνει το ASCII art banner στην αρχή
- `clear_screen()` — καθαρίζει την οθόνη (cross-platform: `clear` σε Linux/Mac, `cls` σε Windows)
- `main()` — κύριο loop: παίρνει input, ελέγχει μήκος και ειδικούς χαρακτήρες, δείχνει αποτέλεσμα

## Πράγματα που δεν ελέγχονται ακόμα (ιδέες για επέκταση)

- Κεφαλαία γράμματα (`str.isupper()`)
- Αριθμοί (`str.isdigit()`)
- Σύγκριση με λίστα από κοινά/αδύναμα passwords (π.χ. `"123456"`, `"password"`)
- Απόκρυψη του κωδικού κατά την πληκτρολόγηση (π.χ. με `getpass` module αντί για `input()`, ώστε να μη φαίνεται στην οθόνη)
- Μετατροπή των συναρτήσεων ελέγχου (`check_length`, `check_special_chars` κ.λπ.) σε ξεχωριστό module για επαναχρησιμοποίηση σε άλλα scripts

## Σημείωση ασφαλείας

Αυτό το script είναι εκπαιδευτικό εργαλείο και τυπώνει τον κωδικό στην οθόνη (`print`). **Μην το χρησιμοποιήσεις για πραγματικούς/ευαίσθητους κωδικούς** — μόνο για δοκιμές και μάθηση.
